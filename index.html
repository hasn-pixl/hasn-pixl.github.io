⚡ HyperShorts

The video tool behind the Zappardy YouTube channel

HyperShorts is a private tool that makes short animated science explainer videos (YouTube Shorts) for the Zappardy channel. For each topic it writes a script, records the narration, builds the animation, and then uploads the finished video to the channel owner's own YouTube channel and schedules when it goes live.

It runs on the channel owner's own computer and is used only by the channel owner. It is not a public service and there is nothing to sign up for.

How it uses YouTube

When the channel owner connects HyperShorts to YouTube, it asks Google for permission to upload videos to that channel and to read the channel's basic details and its list of scheduled videos, so it can pick the next free time slot. It uses the YouTube Data API and follows the YouTube API Services Terms of Service.
